# Kill Confirm Overlay 5.9.2.4

本版集中修复界面布局、游戏设置隔离及首次播放问题，并使用新的 KCF 应用 Logo。

- 修复状态灯与文字对齐、测试事件列表空白和底部滚动、UWP 游戏选择图标裁切。
- 战斗与视效面板统一来源 Logo、游戏名和标题，CS2、CS:GO、LOL 设置分别保存。
- LOL 本地服务页仅保留对局数据源和轮询设置；移除无关目录、CS 端口及当前集成不支持的观战选项。
- 三个游戏来源均移除退出游戏后自动关闭；统一音效与角色语音打断设置的名称和顺序。
- 修复 CF UWP 图标包预载卡住及小翅膀显示范围；提前准备 CF、三国杀动画，减少首次播放等待。
- 修复首次使用语音包时可能因重复初始化音频输出而中断的问题。
- 改善战地 2042 骷髅缓存分辨率及三角洲行动的缩放采样。
- 卡拉彼丘继续使用原版小包和原 1× 内置素材；已取消高清大包与 BC3 压缩试验。

用户安装包为 Windows x64 单个 EXE，包含离线依赖。外置素材继续以工作区 `导入素材/README.md` 和 `素材清单.json` 为准，独立导入。

修改已完成隔离 UI、来源设置、预载及音频回归验证，记录见 [控制面板验证](control-panel-ui-validation.md)。安装包通过正式 Release 构建后另附文件版本、签名和 SHA-256 校验。隔离验证不等同于真实游戏对局及全部声卡环境验收。
