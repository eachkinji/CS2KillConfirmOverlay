# 兼容显示

这是独立的桌面透明窗口宿主，适用于窗口和无边框全屏。在控制面板默认打开的「主页」选择「兼容显示模式」开启，无需安装或运行 Xbox Game Bar。主页同时提供 Game Bar 模式的使用指引；通用配置集中在左侧第二项「高级设置」，与各游戏卡片平级。独占全屏不在支持范围内。

## 文件隔离

- 本项目独立编译为 `KillConfirmCompatibility.exe`，使用 WPF 编辑窗口、原生分层播放窗口和桌面 Win2D；不引用 Widget 项目或其渲染源码。
- Win2D 激活工厂绑定宿主自己的 DLL，避免安装包根目录注册的旧 UWP Win2D 被新宿主加载。原 Game Bar 进程的组件注册保持不变。
- `Renderer/` 是独立的渲染基线，包含现有 15 种风格及弹幕。后续兼容显示的渲染改动只在这里维护，不回写 Game Bar 渲染器。
- `Contracts/` 定义新配置；`Integration/` 是独立模块，仅编译到设置应用，不编译到桌面宿主。`Integration/Home` 和 `Integration/Controls` 保存独立的主页逻辑与各游戏设置界面，不加载旧渲染控件。
- 位置、缩放、显示器及显示开关存放于 `%LOCALAPPDATA%/KillConfirmOverlay/UserData/CompatibilityDisplay/display.json`。运行状态写入同目录的 `status.json`；并发更新使用锁和原子替换。
- 两种显示方式共用已有游戏事件、音频服务和用户选择的资源包。资源目录只读，兼容宿主不执行旧资源库的迁移或目录保存。
- 旧文件只接入设置入口、启动参数、模式互斥和打包；没有加入兼容渲染分支。安装集成单独放在 `Installer/Scripts/CompatibilityDisplay/`，服务启动桥接单独放在 `infrastructure/compatibility.rs`。

## 布局与运行

主页顶部提供模式选择与使用步骤。大卡片下方是与页面卡片同款的横条，左侧用 SVC / CFG / GSI / ANI 四盏状态灯显示后台服务、显示端、游戏数据和素材状态，右侧是当前游戏选择；Game Bar 模式继续显示小组件状态与红绿灯，兼容显示模式下方以素材和测试为主页面，显示范围、布局与性能合并在同一张卡片中，页面右上提供「当前游戏设置」跳转按钮。「预览效果」执行完整的画面与音频预览。素材和测试第一行是语音包、图标包，第二行左侧是播放音量、右侧是测试事件，播放、循环、重载音频和弹幕测试位于第二行最右侧。战斗与视效等逐游戏设置通过「当前游戏设置」进入对应游戏页面。通用设置、服务端口、进阶设置及版本信息由独立的「高级设置」导航入口承载。

各风格分别保存准星、下方反馈、上方反馈（MW2019）、弹幕区域的位置和缩放。下方徽章跟随下方反馈。位置和大小通过「编辑屏幕」直接操作：先在顶部选择上方（橙）、中间（蓝）、下方（绿）或弹幕（紫）；仅选中区域接收鼠标，其他框穿透，重叠时也能独立编辑。拖动移动、右下角手柄或滚轮缩放、方向键微调、Shift 加速、Enter/Esc 保存退出。右键可居中、隐藏或重置元素；设置页可重置当前游戏的布局，没有位置/大小滑条。

普通模式使用置顶、透明、鼠标穿透且不抢焦点的窗口；编辑时启用鼠标输入。默认跟随 CS2/CSGO 客户区，切出游戏后隐藏；可选择显示器、关闭跟随和隐藏。帧率选择与固定 FPS 状态标记已移除，旧的 30 FPS 配置统一恢复为 60 次/秒的内部呈现上限。Ctrl+Alt+O 切换显示，Ctrl+Alt+L 切换布局编辑。

两种显示模式使用单一选择。开启兼容显示先停止 Game Bar 事件接收、释放旧渲染并显示暂停提示；桌面宿主等待旧页面停止确认后才出图。切回 Game Bar 时先关闭桌面宿主，进程生命周期桥接只处理当前安装包的宿主路径，并写入请求编号对应的停止确认；确认前继续阻止 Game Bar 显示。

游戏菜单只创建一次。游戏变更退出原生选择回调后处理，资源选择初始化串行执行，并在异步读取后丢弃已过期游戏的结果，避免选择回调中清空菜单导致的 WinRT 重入。

Win2D 绘制透明图像，播放时通过 UpdateLayeredWindow 在一次调用中提交像素、窗口位置、裁切尺寸和透明度，避免移动原生窗口与 WPF 图像布局分帧生效造成跳动。布局编辑和弹幕仍使用 WPF 窗口。独立后台时钟等待 DWM 刷新，再向 UI 线程提交至多一个待处理的帧；动画推进与绘制共用该时钟，以 60 次/秒为呈现上限；素材序列仍按自身帧率取帧，不改变动画速度。素材尺寸变化立即同步窗口，窗口受屏幕边界限制时仍保持素材比例。反馈和弹幕按最终物理像素重绘，缩放和 DPI 增大时不降采样。先记录绘制指令，再按指令范围与屏幕交集创建原生分辨率纹理；只裁掉透明/屏外区域。CF 图片的透明边缘在原始分辨率扫描一次并缓存，所有非零透明度像素和滤波保护边保留。复用回读缓冲；守望先锋移除画布中始终透明的边缘，保持卡片、入场横条和五行连杀完整，文字排版随卡片复用，移动速度不依赖帧率。各游戏反馈层按可见像素缩小透明窗口并保留屏幕位置、比例和光效；编辑布局时恢复完整区域，切换包和缩放时先重新绘制，再原子提交像素和位置。状态心跳在后台写入，文件占用重试不阻塞动画线程。此实现仍包含像素回读，实际流畅度需在游戏实机上确认。没有注入或修改游戏进程。

## 构建与验证

`ControlPanel/Build-DesktopPayload.ps1` 发布原控制面板与兼容宿主，合并为一份普通安装目录，共用运行库、素材、音频与后台。控制面板复用原 XAML 和业务逻辑，只有桌面 API 适配层，不维护第二套面板。主程序不需要 MSIX、Game Bar、商店或防火墙服务。可选 MSIX 仅包含小组件和小型启动桥接，图片通过已认证的本地后台按需读取缓存。

Assets 由控制面板项目发布一次，不再额外复制整个目录；弹幕只包含运行时 JSON，不携带标注工具、批次、源码和缓存。发布末尾运行 `ControlPanel/Assert-DesktopPayloadResources.ps1`，检查资源数量、哈希和嵌套目录，防止重复打包回归。

`CompatibilityHost/Validation/Test-Presentation.ps1` 使用隔离数据和本地协议夹具，检查刷新节奏、暂停与恢复、等比变换，以及瓦罗兰特和守望先锋的真实预览；分别测试普通尺寸与三倍缩放，输出 PNG 和采样帧数；新增 100/200/300/400% 一像素条纹检查，验证放大时不重采样模糊，以及四色重叠区域的独立鼠标输入。包含 72 次不同裁切和缩放尺寸下的固定标记检查，验证颜色更新、负屏幕坐标及不抢焦点；全游戏审计在每次提交后检查几何位置，不再先调用 UpdateLayout 掩盖中间帧错位。帧数用于诊断，不代表所有显卡都能达到内部呈现上限。

```powershell
./CompatibilityHost/Validation/Test-CompatibilityDisplay.ps1 -CrossfirePack '路径/穿越火线—原版—图标包.zip'
```

验证使用独立临时配置和资源副本，检查配置边界、并发更新、风格隔离、损坏配置、原生鼠标/焦点标志，并将 15 种风格的实际 Win2D 像素导出为 PNG。CF 默认原版图标与斯沃特保卫者语音随主程序附带；其他 CF 包仍单独分发。安装目录的 DefaultPacks 只保留一份，两种显示模式共用；导入的同名包优先。

同一验证还检查弹幕像素、跨进程设置变化、认证连接、后台注册、切出隐藏，以及关闭后的退出和注销。

`ControlPanel/Test-Standalone.ps1` 检查原主页、高级设置、15 种游戏页面、60 次切换、真实播放、弹幕、对话框、弹出层与模式互斥，并确认控制面板、兼容宿主、后台均无包身份。

`ControlPanel/Test-WidgetBridge.ps1` 注册独立测试包，检查桥接启动的后台无包身份、共享配置、图片字节、认证与资源目录权限，最后删除测试包。此测试不等于实际 Game Bar 画面验证。

`CompatibilityHost/Validation/Test-InstallerFallback.ps1` 模拟无防火墙服务、无 Game Bar 及跳过 MSIX 的安装路径，不修改本机防火墙。

旧的 `Test-PackageIdentity.ps1` 和 `Test-CompatibilityWorkspace.ps1` 仅对应 49 版整包架构，不作为 51 版验证入口。当前验证均隔离配置。

### 瓦罗兰特图层一致性

颜色矩阵与阴影效果按每次绘制独立创建，不能在同一命令列表中反复修改共享效果对象：延迟回放会使先前图层改用后面的贴图和参数。`--validate-valorant-composition <output> <assetsRoot>` 对比直接绘制、命令列表绘制和原生窗口实际提交像素；包含 1～6 杀、普通/爆头、完整六杀时间线及约 208% 缩放。设置 `KILLCONFIRM_VALORANT_TEST_PACK` 可加入隔离配置中的外部图标包；`KILLCONFIRM_VALORANT_CATALOG_TEST=1` 对已发现图标包抽帧检查。

### 素材下拉框与 UWP 游戏切换

两种显示模式的素材选择器均使用数据项和虚拟化列表，只为可见项加载缩略图，限制解码尺寸和并发。UWP 单文件请求不再下载整个素材目录。`ControlPanel/Test-Startup.ps1` 使用导入库副本，检查实际展开耗时、已生成的可见选项数量和选中项缩略图。

UWP 共享设置以实际值差异检测本地更改，避免依赖在打包运行时未触发的 `LocalSettings.Values.MapChanged`。发送前和收到快照后均检查本地变化，保留请求期间的新编辑和失败后的待发送值；本地写入的确认不触发整页刷新。游戏刷新串行合并，过期加载不再覆盖新游戏。

`Widget/Validation/Test-GameSwitch.ps1` 使用独立签名测试包及素材副本，验证真实 UWP 控件的 15 种游戏、快速切换、双向同步、请求期间编辑、失败重试与缩略图。测试需以 `WidgetSwitchValidation=true` 编译；协议夹具仅在该测试构建中启用，不需要改变本机网络权限，也不启动用户的后台。该检查不替代实际 Game Bar 宿主的画面验证。
