# 自定义模块：逐帧图标包

## 功能分工

- **图标包库 → 自定义**：创建逐帧图标包。为第 1～5 杀分别“选择素材”或“素材目录”，自动区分 PNG/JSON 图集和散帧；爆头变体可展开配置。文件不需要手动改名，散帧由程序生成图集与配置。
- **图标包库 → 编辑**：替换或清除某个等级的素材、改名、设置素材自身的 FPS 和末帧停留。先在新目录完成校验，再替换目录记录；保留包标识和可见性，不产生重复包。取消或保存失败不改变原包。
- **图标包库 → 导入目录 / ZIP / 导出**：管理整套素材包。导入不会自动切换当前选中的包；缺项和不支持的内容会在结果中提示。
- **自定义模块高级设置**：仅保留计数方式、FPS/末帧停留覆盖、淡入淡出、爆头变体优先规则。
- **效果测试、缩放、偏移、位置**：继续使用项目已有的测试体系与通用显示设置。素材编辑器和模块设置页都不增加独立播放器或显示调整控件。

默认没有内置素材；没有选中素材时不显示动画，不回退到 CF 图标或音效。

## CS2 Customizer 包兼容

兼容范围是包解析和导入规则，不引入 Python、Qt、原程序设置页或预览体系。

标准包可直接包含以下文件，也可以有外层目录：

```text
我的素材/
  style.json          # 可选：名称、作者、版本、说明等
  1.png + 1.json      # 1～5 杀图集；不要求提供全部等级
  2.png + 2.json
  1hs.png + 1hs.json  # 可选：同等级爆头变体
```

- 标准包 PNG 和 JSON 在未编辑时按原始字节保存。导出包含标准 PNG/JSON、名称与等级列表。
- 选择 PNG 时先查找同名 JSON，选择 JSON 时查找同名 PNG；也可以同时选择二者或选择包含一组图集的目录。图集按 JSON 的帧宽高、列数、帧数识别，不能把整张 PNG 的宽高当成单帧尺寸。若 UWP 文件选择权限不包含相邻文件，会提示选择目录或同时选择 PNG/JSON，不越权读取。
- 单个槽位不能混选多组图集或图集与散帧；整套多等级素材仍走图标包库的整包导入。已存在但损坏的 JSON 会报错，不退回成一张静态帧。
- 可选的 `style.json` 格式损坏时提示并忽略；缺少名称时使用外层目录名或 ZIP/目录名。`preview.png`、`readme.txt`、`readme.md`、`license.txt` 会保留。
- 与参考 `probe_pack` 相同：存在标准 PNG/JSON 对时，优先导入这些标准条目，不完整对会提示并跳过；没有标准对时才解析松散素材。
- 松散素材识别 `1～5`、`kill1`、`1kill`、`single`、`double`、`triple`、`quad`、`ace`、`penta`、中文击杀名称，以及 `hs/headshot/head/爆头` 后缀。额外保留旧版 `kill1-1/～kill1-5/` 兼容。
- 同等级候选优先级为 JSON → 图片 → 帧目录；普通和爆头目录都可导入。旧版目录的 FPS/停留侧边 JSON 仍可使用。
- 帧目录与手动选帧按**文件名最后一组数字**排序，相同数字再按文件名排序；`2.png` 在 `10.png` 前。这对应参考导入器，区别于参考旧播放器直接读取目录时的字典序。
- 静态 PNG/JPEG/BMP、系统解码器支持的静态 WebP 可导入；帧尺寸不一致时在最大画格中居中补透明边。独立帧画格最长边超过 1024 时按统一比例缩小并提示，再拼成图集；标准图集不走此转换。单帧素材默认末帧停留 1 秒，可在编辑时修改。
- **本轮不扩展 GIF、APNG、动画 WebP、AVIF 或 Aseprite JSON 转换。** 这些素材请先在 CS2 Customizer 导出成标准图集包再导入。不要把多帧动图当作一张静态帧。
- 部分等级无法导入时报告具体原因；无可用等级时不注册新包。手动编辑采用全部成功才保存的规则。

每个等级的 JSON 示例：

```json
{
  "frame_width": 256,
  "frame_height": 128,
  "frames": 30,
  "cols": 6,
  "rows": 5,
  "fps": 30,
  "hold_seconds": 0.5,
  "loop": false,
  "version": 1
}
```

## 播放与安全

沿用现有 Win2D 渲染、时间驱动选帧和 GPU 纹理分页。新击杀替换当前动画，第 6 杀及以上使用第 5 杀；爆头缺失时使用同等级普通素材，该等级也缺失则不显示。编辑替换包后，缓存按新的素材目录重新加载。

FPS 范围 1～60、停留 0～10 秒；模块设置覆盖不会改写素材本身或导出的 ZIP。淡入 0.12 秒、淡出 0.25 秒，可关闭。

每个变体最多 600 帧，超出时明确提示截取。原生图集的单个画格边长最大 4096，整张图集边长可以超过 4096，由运行时分页；源图集或单张独立帧最多 67,108,864 像素。独立帧转换后的画格最长边为 1024。ZIP 最多 3200 项、解压后合计最多 512 MiB，压缩比最大 500；JSON 最大 1 MiB，附加文件各最大 16 MiB。

保留越界路径、大小写重复路径、符号链接、解压大小和图像几何检查。安全检查失败时整个 ZIP 拒绝解压；失败的临时副本会清理。删除和编辑只处理库中拥有的副本，不修改源文件。

## 验证

`Test-CustomSequences.ps1` 使用实际格式、导入、编辑、目录持久化和导出代码，以及 Windows 图片解码器和文件 API。测试需要 PowerShell 7、Visual Studio C# 编译器、.NET Framework 4.8 或 4.8.1 引用程序集和 Windows SDK 10.0.26100.0。

```powershell
pwsh -NoProfile -File .\Test-CustomSequences.ps1
python .\Tests\CustomSequences\compare_reference.py ..\workshop\cs2-customizer <测试输出的 GUID 目录>
```

参考库为 [gufan0000/cs2-customizer](https://github.com/gufan0000/cs2-customizer)，本次对照提交 `9b82506`。对照脚本执行本地原库的函数，验证播放时间状态、等级别名、数字排序、PNG/JSON 图集识别、独立帧规范尺寸、标准/松散包规则及导出 ZIP；不复制参考实现到产品，不启动 Qt。图像探测对照需要 Pillow。

编译与自动检查不替代安装后的图标包库操作、现有测试入口及 Game Bar 实际显示验收。
